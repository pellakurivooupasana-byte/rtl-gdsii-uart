# UART Controller | RTL-to-GDSII using OpenLane

## Overview

This project implements a Universal Asynchronous Receiver Transmitter (UART) Controller in Verilog HDL and demonstrates the complete RTL-to-GDSII ASIC design flow using OpenLane with the SKY130 PDK.

## Features

- UART Transmitter (TX)
- UART Receiver (RX)
- Functional Verification using ModelSim
- RTL-to-GDSII Implementation using OpenLane

## Tools Used

- Verilog HDL
- ModelSim
- OpenLane
- OpenROAD
- Yosys
- Magic
- KLayout
- SKY130 PDK
